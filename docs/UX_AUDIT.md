# RecallRelay UX audit

Baseline inspection in Chromium at 1440 × 900, 1024 × 900, and 390 × 844 CSS pixels. The mock workflow supplied normal, empty, loading, warning, and failed states. Isolated HTTP fixtures supplied pending and reconnecting states. I compared the browser captures with the 12 Stitch references and checked action bounds and dialog focus in the browser.

| Severity | Screen | Finding | File to fix |
| --- | --- | --- | --- |

| Major | Setup | The three steps are implicit, Seed stays prominent after seeding, and real approval replaces the setup tab. The disabled Continue button gives keyboard users no explanation. | `frontend/src/pages/Setup.tsx` |

No horizontal viewport overflow was observed in the baseline captures. The existing icon-plus-text status pairs and the three outcome colors carried through the reference. The verification pass checks accessibility again after layout and copy changes.
