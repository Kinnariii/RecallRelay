1. Normalize the reference paths and scaffold the Vite application, shared shell, routes, and Stitch tokens.
2. Define and validate the API contract. Build shared UI and isolated, persistent mock logic with unit tests.
3. Build Setup, Notice, Review, and Result in order, including extraction evidence, approval, and refund retry.
4. Finish Home and system states. Check responsive layouts and accessibility.
5. Run browser acceptance tests in mock mode and exercise the real adapter against a contract stub. Document setup and handoff.

Keep each milestone runnable. Use the Stitch export for visual hierarchy and the spec for behavior.
